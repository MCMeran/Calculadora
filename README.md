
# 🧮 Calculadora en Java

## 📋 Descripción
Este proyecto implementa una **calculadora básica en Java** con operaciones de suma, resta, multiplicación y división.  
Incluye **sobrecarga de métodos** para manejar distintos números de parámetros (2, 3 y 4 valores).

---

## 🚀 Características principales
- Operaciones aritméticas básicas: `suma`, `resta`, `multiplicacion`, `division`.
- Manejo de errores en la división (no permite dividir entre cero).
- Sobrecarga de métodos para trabajar con diferentes cantidades de argumentos.
- Ejemplos de uso en el método `main`.

---

## 🧠 Estructura del código
El archivo principal es `Calculadora.java` y contiene:

| Método             | Descripción                        | Parámetros |
|--------------------|------------------------------------|------------|
| `suma()`           | Suma los valores                   | 2, 3 o 4   |
| `resta()`          | Resta los valores                  | 2, 3 o 4   |
| `multiplicacion()` | Multiplica los valores             | 2, 3 o 4   |
| `division()`       | Divide dos valores (maneja errores)| 2          |

---

## ⚙️ Cómo ejecutar el programa

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/Calculadora.git
   ```

2. **Accede al directorio del proyecto:**
   ```bash
   cd Calculadora
   ```

3. **Compila el código:**
   ```bash
   javac Calculadora.java
   ```

4. **Ejecuta el programa:**
   ```bash
   java calculadora.Calculadora
   ```
